# Architecture

## 1. Цель системы

Система распознавания лиц предназначена для автоматического пропуска сотрудников через проходные офисного кампуса с целевым временем принятия решения до 1 секунды p95. При сомнительных или рискованных случаях система не открывает турникет автоматически, а переводит событие на ручную проверку охране.

Ключевой принцип архитектуры: false accept существенно опаснее false reject, поэтому при недостаточной уверенности система выбирает `manual_review` или `deny`, а не `allow`.

## 2. Архитектурный подход

Используется гибридная архитектура с основным inference на edge-устройствах проходных.

Причины:
- низкая задержка и достижение p95 < 1 секунды;
- работа при временной потере связи с центральным сервисом;
- уменьшение передачи биометрических данных по сети;
- снижение зависимости критического горячего пути от центральной инфраструктуры.

Центральный сервис отвечает за:
- master-базу сотрудников и прав доступа;
- выпуск и отзыв biometric templates;
- распространение обновлений на edge;
- централизованный audit log;
- мониторинг;
- управление версиями моделей и политик доступа.

## 3. Основные компоненты

### Edge на проходной

На каждой проходной расположен edge-узел с GPU.

Горячий путь:

1. Получение кадра с камеры.
2. Детекция лица.
3. Проверка качества изображения.
4. Alignment лица.
5. Liveness / anti-spoofing.
6. Получение face embedding.
7. ANN-поиск по локальному индексу сотрудников.
8. Проверка top-1 score и margin до второго кандидата.
9. Проверка локальной access policy.
10. Decision Engine принимает `allow`, `manual_review` или `deny`.
11. Для `allow` отправляется идемпотентная команда турникету.
12. Событие записывается в локальный audit buffer и отправляется в центральный audit service.

### Центральная система

- Employee / Identity Service — данные сотрудников и статус доступа.
- Biometric Template Store — зашифрованные embeddings.
- ANN Index Builder — формирование актуального индекса для edge.
- Policy Service — правила доступа.
- Model Registry — версии CV-моделей.
- Audit Service — долговременный аудит решений.
- Monitoring — технические, ML и бизнес-метрики.
- Security Console — ручная проверка сомнительных случаев.
